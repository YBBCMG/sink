记忆当铺

只收回忆，不收金银 —— 完整通关教程

〇 · 一句话搞懂这游戏

你是一个忘了为什么难过的人——妹妹小满在雾里消失了七夜。解开小镇谜团需要 三件信物，而工具和线索全都要用自己的记忆去当铺换。卖掉的记忆会真的从游戏文本里消失，过期不赎回就永远断当。游戏分三幕：找信物只是第一幕——里屋的门后，故事才真正开始。

二 · 三条铁律（比攻略更重要）

  1. 3 分钟赎回期：典当后的记忆有 180 秒可赎回——回当铺柜台，花原价（当多少，赎多少）。超时即「断当」，永远散进雾里，文本变删除线。
  2. 完整度 30% 红线：自我完整度 = 还未典当的记忆权重 ÷ 34。跌破 35% 有警告音，跌破 30% 立即触发坏结局「空白之人」——不需要走到结局，半路就结束。
  3. 雾门清算断当：最后进雾门时，只要有断当（哪怕 1 段），就无法到达最好的结局——典当中的记忆不算断当（花钱赎回就恢复）。别把当金花光，留出赎回钱。
价格规则：典当永远全价，赎回永远原价——"卖了又赎"一来一回净赚 0，当金刷不动。钱的正途只有一条：告示牌零工（3 个委托共 +4◆）。零损失通关的完整路线见下方 Step 1–7。

三 · 开局怎么走（无剧透版，只想自己摸索就看到这里）

1
开局在镇中心路口。左边是记忆当铺（门口按 E 开柜台），路口旁立着告示牌——手头紧就先去接零工（完整路线见第四节）。
2
选「典当记忆」，卖一段换◆当金（越痛的越值钱）。先卖便宜的练练手完全没问题。
3
选「看看柜台」用当金买当票——当票是从你卖掉的记忆里抽出来的实物，所以有的商品要求你先卖掉对应的记忆。
4
带道具去镇上三处旧地：教堂侧门（东北）、钟塔（东北角）、码头闸门（东南），各取一件信物。谜题卡住可以花钱问 NPC（老渔夫、唱诗班孩子各 1◆），或者回家看墙。
5
集齐三件信物 → 回当铺找老板「谈谈妹妹」→ 推开里屋的门——故事在这里才真正开始（第二幕）。结局收集跨局累计，四个都值得一拿。

四 · 第一幕：三信物与零断当路线（7 步）照做即可无伤进第二幕

1
开局先去告示牌（镇中心路口），把 3 个零工全部接下——渔家的委托、教堂的求助、孩子的请求，共值 4◆。交差点恰好就是你待会儿要去的三个信物地点，顺路结算。
2
进当铺柜台 →「典当记忆」卖掉「井沿缺角藏钥匙」（童年，+2◆）→「看看柜台」买铜钥匙当票（−2◆）。当金归零，但 3 分钟赎回计时开始了——别耽搁。
3
往东北走到教堂侧门按 E：交「诗篇」委托 +1◆，再用铜钥匙开锁 → 半张照片 ①。
4
旁边的钟塔按 E：交「歌谱」委托 +2◆；面板写的是暗语——"哑的那一下，乘上塔上从不乱的那个数"。要两个数相乘：哑掉的是第七下（记忆「那晚钟声很乱，第七下是哑的」），塔上从不乱的是六下（记忆「钟塔整点敲六下，从不曾乱」）→ 输入 42 → 旧怀表 ②。卖掉这两段记忆，题面的数字就会变成黑块；答错两次面板才给提示。
5
往东南到码头闸门按 E：交「鱼篓」委托 +1◆；再按 E 敲暗号——面板只给六个空位和两处线索：记忆里的「钟声三长两短」，加侧框新刻的「敲完再补一声长的」→ 长、长、长、短、短、长（六拍）→ 她的发绳 ③。（敲错只清零无惩罚，并告诉你错在第几拍。暗号兜底：回「你的家」看墙上刻痕。）此时当金 4◆。
6
赶回当铺 →「赎回记忆」→ 原价赎回「井沿缺角」（−2◆）。钥匙不会消失，记忆完好无损，净支出 0。想看雾巷的小围巾就顺手买雾灯（−1◆）——纯剧情彩蛋，不影响结局。
7
回柜台 →「谈谈妹妹」→ 老板开门 → 点「推开里屋的门」——里屋不是结局，是第二幕的转折点：你会读到她的字条，知道她叫小满，以及五页日记的存在。
时间充裕度：全图跑一圈纯移动不到 10 秒，180 秒赎回期绰绰有余。整条路线当金最低点出现在买完钥匙的 0◆——所以先接零工再买钥匙是本路线的骨架。

六 · 第三幕：雾门 · 三连问 · 最终抉择

  1. 进雾门：雾巷深处（东北角，教堂右上方）出现发光的雾门，按 E 进入雾的那一边。
  2. 三连问（答错任意一句 = 直接坏结局「一半的我」，一局作废；答案全在前两幕里，进门前先确认自己记得）：
问题正确答案答案来源
她最怕的不是黑、不是雾，是什么？放学一个人回家的那段路记忆「fear」/ 日记里的她
雾起时的暗号是几长几短？三长，两短记忆 / 家墙刻痕 / 渔夫
答应她什么时候去看海？雾季一结束记忆「sea」/ 日记页五
  1. 最终抉择（三问全对后）：带她回家 = 结局「雾散」；让她留在雾里、自己当守灯人 = 隐藏结局「守灯人」。两个都值得拿。
  2. 断当惩罚在雾门结算：进雾门时只要有断当（1 段也算），她拼不出完整的你——直接进入「一半的我」。想要真结局，先去柜台原价赎回。
  3. 怕答错？两道保险：① 三段"自带答案"的记忆（fear / code / sea）别卖、或卖赎自如留着；② 侧边栏「剧情」页随时能复习三幕线索。开发者模式（` 键）里「⏭ 跳过对话」也会自动替你答对。

十 · 四个结局怎么解锁

结局条件
雾散（真结局）走完三幕：三信物 → 五页日记 → 雾门三连问全对 → 抉择「带她回家」。要求：进雾门时断当 0 段（典当中的不算，赎回即恢复）
守灯人（隐藏）同上走到最终抉择，但选「让她留在雾里」。一个关于守约而非挽回的结局
一半的我两条路：① 走到雾门但有断当（1–4 段）——她拼不出完整的你，三连问会被跳过；② 断当 0 段但三连问答错任意一句——话没记全的人，当场散场
空白之人断当 ≥ 5 段，或完整度跌破 30%——随时可能触发，不需要走到雾门

刷结局技巧：

  • 拿「守灯人」：正常打到最终抉择选留下即可（速度最快的一局：接零工 → 卖井钥匙买钥匙 → 三地拿信物 → 里屋 → 五页 → 雾门）。
  • 拿「一半的我」：随便卖一段 1◆ 的等它断当，再走完雾门（或者更快的——进雾门故意答错一题）。
  • 拿「空白之人」：把 1◆ 的五段（桂花香 / 喝醉 / 父亲 / 钟六下 / 当铺帮工）全卖掉等 3 分钟。
  • 结局收集存在浏览器本地，跨局累计；结局画面会显示已解锁列表。

十一 · 冷知识与细节

  • 自动存档：进度每秒自动保存，关掉页面下次打开接着玩；顶栏「↺ 存档点」可以回到本章开头（每章开头自动记一次，序章还没记过时会提示）。结局收集不受影响。
  • 顶部 HUD 的「赎回」倒计时显示的是最紧迫的那条记忆。
  • 完整度跌破 35% 时，底部操作提示会开始黑块化、伴随一声警告音——那是最后的刹车。
  • 井的地图名「童年之井」在你卖掉那段记忆后会变成 ？？？？——地图本身也会失忆。
  • 敲错暗号只清零进度，无任何惩罚；钟塔谜题答错也只是闪红光，可以一直试。
  • 和老板「谈谈妹妹」在集齐信物前后台词不同；里屋的门在柜台菜单里推开（「推开里屋的门」按钮）。
  • 告示牌上除了零工，还贴着一张寻人启事——女孩，十二岁，雾夜走失，至今七日。她是谁？

十二 · 正篇《雾季十年》攻略三幕三章 + 隐藏章 · 四个小游戏 · 四个新结局

核心规则：正篇里你的「完整」在计息——每走完一章（一幕）结算一次利息，小游戏失手也会添息。利息越高，终章越难拿到好结局。三件证词是终章的钥匙：档案员的卷宗、渔夫的断当实物、灯婶的家谱——全部在第 1 章里收齐。

正篇只有 3 章（一幕一章：漏 / 账 / 赎）+ 1 个隐藏章。每章内部由 3~4 个段落串成，段落收尾会演一小段小结过场；只有一章走完（幕末）才弹整章结算——利息与雾季倒数都在那时结算。

四个小游戏怎么玩

  • ① 音序记忆（守夜 / 上堰）：灯板依次亮出一段曲子，你看完按原顺序点回来。守夜 3 段越接越长（5→6→7 音），上堰 2 段更快。技巧：嘴里跟着哼、记「颜色方位」而非音名。点错一次 +5% 利息，可无限重试。
  • ② 机芯校准（钟楼）：指针在表盘上转，指针走进金框弧的瞬间按 E。4 段一轮比一轮快、窗口一轮比一层窄（最后一层只有 24°）。技巧：别盯指针，预判它回到窗口的时机提前半拍按。失手 +5% 利息。
  • ③ 敲钟节拍（那一夜）：光圈从外圈滑向钟线，光圈压线的瞬间点——按谱面敲「三长两短」，10→12→16 音逐段加长。容错只有 2 次、空击（点空）也算错，失手 +8% 利息。技巧：长音间隔大、短音密——心里数「哒——哒——哒、哒」的节奏，别看手。
  • ④ 忏悔簿对账（纯推理，v22 起每局现生成）：六行旧账、五条批注（单数年当入赎出 / 雾季八年封市 / 先生的名字不入账 / 当入行都按指印、补写的行指印后按 / 询价行不押指印）。恰好一行同时违反两条批注——那就是后补写的那行；另有至少两行只违反一条，是专门摆在那儿诱你在第一处不合规就下笔的幌子。答案每局都变，背不下来，但唯一解由生成器保证。答错 +5% 利息，并当场告诉你那一行只犯了哪一条批注。技巧：别找"有毛病的那行"，要找"同时踩坏两条尺子的那行"——六行横过来，一条批注一条批注地画掉。
  • ⑤ 钟塔哑钟（v22 加难）：面板只给暗语「哑的那一下，乘上塔上从不乱的那个数」——两个数都得从你自己的记忆里翻：7 × 6 = 42。把这两段记忆当掉，题面上的数字当场变黑块（当铺抽屉里那两段，字是黑的）。

利息经济学

  • 章节结算 +5%~+10%，第1章断片 +10%，小游戏失手 +5%~+8%——满打满算 50% 上下，想要隐藏结局就要省着点。
  • 正篇里当金来路照旧：告示牌零工、典当记忆。终章「替全镇还息」要花 利息的一半◆——第 3 章开打（上堰）之前记得把当金攒够。

终章抉择 · 四个结局

结局条件
灯再亮（真结局）证词 ≥ 3 且当金 ≥ 利息的一半 → 选「替全镇把利息还清」
接柜（隐藏）证词 ≥ 3 且利息 ≤ 55%（少断片、小游戏少失手）→ 选「自己留在门里守灯」
整镇的一半终章恒可选 → 选「只还自己的账」
空账第 2 章（灯匠家谱 · 催当帖）里在催当帖上签了契 → 终章只剩它。想要其他结局就别签
全成就路线：一局不签契、少失手 → 拿「灯再亮」；读档回终章（利息不变）再拿「整镇的一半」；另开一局故意签契 → 拿「空账」；最后打一局省息局拿「接柜」。结局收集跨局累计。

十三 · 开发者模式不想手动通关？按一下 ` 键

  • 怎么打开：点顶栏红色 DEV 按钮，或按键盘 `（Tab 上面那个键）/ F2。面板浮在画面右上角，不挡游戏操作，再按一次关闭。
  • 资源 / 时间：+10◆ / +50◆ / 清零当金；时间快进 1 分钟（测试断当用）。
  • 记忆：「全部恢复」可撤销一切断当与典当（含救回空白结局边缘的自己）；「全部典当」一键清仓拿全部当金。
  • 行囊 / 信物：铜钥匙、雾灯、旧相册、三信物一键入手，不用再去解谜买票。
  • 剧情跳跃：开里屋 → 进二幕 → 五页日记 → 进三幕，四步直通终局；「推雾门」直接进雾境（资格判定照常生效）；「⏭ 跳过对话」自动翻完所有剧情页并自动答对三连问，停在最终抉择让你自己选。
  • 传送：全地点 + 两个 NPC，自动落到能按 E 互动的位置。
  • 选项：穿墙（无视建筑碰撞）、时间冻结（赎回倒计时定格、永不超期）、移速 1x/2x/3x 循环。
  • 直达结局：雾散 / 守灯人 / 一半的我 / 空白之人，四结局一键解锁（正常计入结局收集）；看完点「↺ 重开一局」马上回初始状态。
  • DEV 开关（穿墙 / 冻结 / 移速）在重开一局后仍保留；正常通关路线完全不受影响——这是纯测试工具。

十四 · 剧情完整梳理看不懂故事再看这节——满级剧透，通关后阅读体验最佳

一句话概括：妹妹小满为了替哥哥背上"忘性"，把自己典当给了雾；你集齐她留下的三样旧物和五页日记，走进雾里用"三句话"证明你把她的活记全了，才换得她回来。

世界观三条规矩

  • 雾 = 这座镇的忘性：人放不下的东西待久了会散进雾里，成了雾的一部分。所以当铺收的"回忆"，到期断当就真的归雾。
  • 当铺规矩：只收回忆，不收命与名字。当金=记忆的痛感结晶；赎回原价；断当归雾不归铺。老板是守规矩的"堰口"，不做好事也不做坏事。
  • 惦记 ≠ 拥有：日记页二里修女说"东西会没，惦记不会"。小满不信，她用整局游戏验证了这句话——惦记到了雾那边也能收到。

七夜前到底发生了什么（藏在日记里）

  • 哥哥（你）的病越来越重，忘性大到记不住妹妹的事。
  • 小满打听到了当铺的事，也知道了"雾门用惦记开"。她在九点三刻（钟停摆的时刻，也是你拨针谜题的答案）数完钟声，自己走进了雾里——她许的愿是"哥的忘性，归我背"（日记页四：井边那个愿是她许的，不是你）。
  • 她怕你找不到她，把要紧的话写成五页日记，藏在你"一定会去的地方"：家、教堂、码头、井、钟塔——全是你和她有共同记忆的地方。
  • 她走后，墙上留下三长两短的刻痕：那是你们兄妹的暗号"到我这里来"。整局游戏里钟声、暗号、敲门，全是这个暗号的变体。

三幕在干嘛

  • 第一幕：集齐三信物（照片/怀表/发绳），证明你和她的过去还在——老板才肯开里屋的门。
  • 第二幕：读五页日记，拼出"七夜前她为什么走、怎么走、留下了什么话"。五页钉成账本，就是你进雾门的"赎票"。
  • 第三幕：雾门三连问=当契作废的仪式。当铺不认眼泪只认证据：三句话全对，才承认"你把她记全了"。

四个结局各在说什么

结局含义
雾散你用"自己的一段完整"抵了当契——她回来了，你却交出了完整（当铺账本上你的名字被撕掉）。但纸船漂进了真正的海，两讫。
守灯人你不赎她了，把日记留给她做伴，自己每夜敲三长两短。她回不来，但暗号一直有人应——关于守约的结局。
一半的我断当散进雾里的记忆都在她身边漂着，可你身上缺了几块，她拼不出你——不是她不肯认你，是当铺的规矩：话没记全，当契不作废。
空白之人你卖得太多，连"为什么来当铺"都忘了。老板转过身——那是你自己的脸。总会有下一个客人。
  • 顺手回收的细节：脸盆里的纸船（结局里漂向海）、桂花（井底油布包里夹着一枚干的）、"家"写成"冢"（她的字，雾门纸船船头那个字）、钟塔第七声（她数到的最后一声）。
  • 旧相册第一页"笑得眯起眼的女孩"——是伏笔，当前版本不影响结局，留作以后剧情扩展。

十二 · 新版三件事（跑腿 · 雾里的东西 · 灯油）

跑腿：任务要跨场景来回跑

  • 主线里有 13 条"跑腿"任务——它们不是"走到某处点一下"就完，而是按顺序跑一条路线，最后还得回来。例：修堤 = 先去镇上看告示 → 再去潮堤堵豁口 → 回镇上报信才算完。
  • 进度写在任务页里：✓ 走过 / ● 这一段 / ○ 还没到，顶上"目标"那行还会告诉你现在该去哪。顺序错了不算，但旗标不会丢 —— 回对了场景照样接上。
  • 一条路线只认"场景"，不认运气：跑错地方不推进，也不会把任务做死。

雾里的东西：一个场景一只

  • 只有一种：雾呓 —— 雾里那声含糊的梦话，兜帽下垂着两粒淡光，身上浮着别人丢下的字。它张一次嘴，你就少一个字。
  • 它们掉不了你的血（这游戏也没血条）——被摸到或吃一发，就咬掉你一段记：先"缺字"，再一口就"碎掉"。碎掉的记在「记」里看不出原句，也不能当。
  • 咬一口就退回雾里消失，一处最多恶心你一次；幕一出不刷，幕二才开始。
  • 灯下安全：门楼与每个可交互点都是灯圈，它们不进圈、也不朝站在圈里的人吐东西。
  • 被咬的记能补：记当铺柜台按伤得深浅收钱（2 枚起）。

灯油：唯一的反制手段

  • 按 F（触屏右下角 F 键）泼一罐灯油：圈里的东西被定住 15 秒，动不了、吐不出；圈还在的时候踩进来的，一样被钉住。
  • 灯油可以买：记当铺柜台 2 枚一罐；开局给 2 罐，每进新的一幕再补 1 罐。
  • 面板开着也能泼 —— 解谜的时候被盯上，就是用它救命。

解谜反噬

  • 有一部分机关错够次数会咬记（九处：算盘、闸板、契文、断句、账本、歌谣、三问、连环锁…）。第一次会先提醒你"再错几次就要咬了"。
  • 连环锁那处最狠：六百秒里五枚环没解完，弹回第一道 + 咬你一段记。
