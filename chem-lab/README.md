# 🧪 元素实验室（chem-lab）v0.1

一个**单文件、离线可玩**的真实化学沙盒游戏：118 种元素、真实热力学物理、自动配平的真实化学反应、
玻璃器皿 + 加热 + 测量仪器，以及看得见的粒子现象（气泡 / 沉淀 / 变色 / 火焰 / 蒸汽 / 闪光）。

**双击 `index.html` 就能玩** —— 不需要服务器、不需要联网、零外部依赖（单文件 367 KB，纯 Canvas 手绘）。

里面还带一套 **📘 初中化学实验教程**：22 个教材经典实验（制氧、氧气性质、催化剂对比、制 CO₂ 与检验、
粗盐提纯、电解水、质量守恒、金属活动性、酸碱中和、生石灰放热、配制溶液），每步都自动判定。

## 怎么玩（30 秒上手）

| 想干什么 | 怎么操作 |
|---|---|
| 放一个容器 | 工作台「仪器」行点「试管 / 烧杯 / 锥形瓶 / 蒸发皿 / 坩埚」（最多 6 个）；中间是一大片空地，摆上来的东西**都能用鼠标拖着挪位置** |
| 加试剂 | 右边**试剂架**点物质 → 填用量（g / mL / mol）→ 加入；单质在**左边周期表**点元素 → 取用 |
| 摆器材 | 工作台「器材」行点 🕯**酒精灯** 250 W ／ 🔥**本生灯** 900 W ／ 🟥**电热板** 600 W —— 它会作为**一件实物**摆到台面上（各自有卡片、有自己的「🔥 点燃 / 💨 熄灭 / ✕ 收走」） |
| 加热 | **三步缺一不可**：① 摆一件器材上台面 ② 把容器**架到它上面**（拖过去，或点器材上的「⬆ 架上来」）③ 点这件器材的「🔥 点燃」。没架上去不热、没点着也不热；熄灭/收走器材立刻停热 |
| 点燃 / 搅拌 / 倒空 / 移走 | 容器卡片上的按钮 |
| 看数据 | 卡片上的 🌡温度 / ⚖质量 / 🧪体积 / 🖊pH：**插上对应的量器就有数**（温度计、pH 计插在容器里是**实时读数**；天平、量筒给一次快照）；哪一项显示「未测 需×××」，**点那一行**就自动把量器摆出来并读数 |
| 看公式 | 右边**现象日志**：每条反应都给出配平后的方程式、条件、现象、ΔH |
| 倾倒 / 过滤 / 导气 / 通电 | 容器卡片第二行：🫗倾倒 ／ 🧻过滤 ／ 💨导气（会弹窗选目标容器）／ ⚡通电（电解水用） |
| 跟着教程做实验 | 右上角「📘 实验教程」→ 选实验 → 「▶ 开始实验」→ **工作台右侧常驻步骤面板**，手把手把该点的按钮点亮，逐步真判定 |
| 把时间快点过完 | 右上角「⏩ 时间 ×1」循环切 ×1 / ×5 / ×20 / **×60**（物理一点没改，只是让同一段时间快点走完；蒸发结晶这种真实实验要等几分钟的步骤，×60 下几十秒看完） |

引导默认开启（右下角 6 条任务），右上角「🎓 引导」可随时关掉变成纯沙盒；进度自动存在 localStorage。

**热源是实物，不是下拉框**（这一版改的）：中间那片空地是台面，容器和加热器材各是一张卡片，
都摆在台面上、都能拖。热量只在「容器确实架在这件器材上」**且**「这件器材确实点着」时才进入系统 ——
`app.heater` 每一步都按实物关系重算，所以挪走、熄灭、把器材收走都会立刻停热。
烧杯这类的传热效率还会被"没垫石棉网"打对折，酒精灯和本生灯的最高火焰温度也不一样（576.9 °C / 1226.9 °C）。
台面排不下时横向滚动，不会出现两张卡片互相压住按钮。

**架上去之后卡片不会被顶出台面**（2026-09-27 修）：容器架到器材上时，底边抬到**量出来的器材卡片真实高度**
（原来写死 112 px，而酒精灯卡片实际 172 px —— 容器会压住灯头和火焰）。
所以 1280×720 的笔记本上「酒精灯 154 + 架着的烧杯 260 = 414 px」也放得进 506 px 的台面
（实测：`benchH 506 / appH 260 / toolH 154 / headroom 95`）。
万一窗口更矮，抬升量会被**限幅**（宁可两张卡片视觉上叠一点，也不让容器顶端跑出台面 —— 那是连拖都拖不回来），
叠的时候容器卡片会自带一圈暖色投影作提示。

**模型一键缩放（2026-09-28）**：台面上所有实物的大小只由 4 个 CSS 变量决定 ——
`--bw` 容器卡片宽 / `--bh` 器皿画布高 / `--tw` 器材卡片宽 / `--th` 器材画布高（在 `src/style.css` 的 `:root` 里）。
JS 的 `ITEM_W` 直接读这同一批变量（`05-lab.js` 的 `cssPx`），不会两边写死后对不上。
这一版把器皿画布从 86 → 64 px、器材画布 58 → 42 px、卡片 168 → 158 / 104 → 96 px；
器皿画布同时收窄到卡片宽度的 64% 并居中（以前铺满整张卡片，改矮之后会显得又矮又胖），
气泡/沉淀/蒸汽的**粒子大小与上升速度按画布高度同比缩放**（`06-view.js` 的 `vk(app)`），所以模型小了不会显得颗粒粗。

**架上去的容器现在真的坐在火上**：容器卡片的上架态（`.appcard.onrig`）把器皿画布挪到卡片**最下沿**
（`order: 9`），而火焰本来就画在容器自己的画布里（`drawFlame`），于是器皿底直接压在火苗上，
卡片再叠在器材卡片正上方 —— 以前器皿画在卡片顶部，隔着两百来像素的按钮区悬在灯的上方。

**🗼 铁架台是个大件（2026-09-28 重做）**：它不再是和酒精灯一样大的小卡片，而是**上下两格的整台装置** ——
上格是铁圈，点「⬆ 上格放容器」把容器架上（容器会**画在铁圈里**，控制卡片自动排到铁架台右边，不叠不挡）；
下格放酒精灯，点「⬇ 下格放酒精灯」塞进去（放进去的灯不再单独占一张卡片，它画在铁架台的下格里），
点铁架台上的「🔥 点燃」＝ 点着下格那盏灯。热量只在「上格有容器 + 下格有灯 + 灯是点着的」时才进入：
`syncHeaters()` 会把这种容器的 `app.heater` 指向**下格里的酒精灯**（带 `viaStand` 标记，传热效率 ×0.9，隔着一层铁圈的距离）。
下格只认酒精灯（本生灯太高塞不进去，会明确告诉你），把这样的灯从下格取出来它自己并没有坏 —— 老玩法「把容器架到灯上」原样保留。

**卡片上的读数是"测出来的"，而且现在会自己更新（2026-09-28 修）**：
- **插在容器里的温度计 / pH 计 = 实时读数**（读数行后面挂一个青色「实时」标签）。真的把温度计泡在液体里，它就是一直读数的；
  以前是"点一次测量 = 一个冻结的快照"，一边加热一边看数字纹丝不动 —— 那才是"温度显示不正确"。天平、量筒仍然只给快照
  （东西一变就标「需重测」；温度按 5 °C 一档判定，慢慢加热时不会每帧都喊你重测）。
- **点读数行 = 缺什么补什么**：哪一行写着「未测 需温度计 / 需天平 / 需量筒 / 需 pH 计」，点它就直接把这件量器摆上台面、
  该插的插进容器、然后立刻读一次数（原来只会在提示里说缺什么，得自己去器材行一件件找 —— "测量不了"多半卡在这）。
- **加热状态行说真话**：状态行读的是 `app.heater`（真正的热源），所以铁架台加热时会写「🕯 酒精灯（在铁架台下格）正在加热
  火焰 576.9°C · 传给容器约 39 W｜⚠ 没垫石棉网，传热效率减半」。以前它读的是"容器架在哪件器材上"，
  遇到铁架台就变成「架在 铁架台 上（还没点着）」，甚至可能写出 `undefinedW · 火焰 NaN°C`。
- 顺带修好了**测量器材的画**：温度计、量筒、pH 计、天平、石棉网、三脚架、玻璃棒、胶头滴管以前全都画成"电热板"的样子
  （`renderTool` 的兜底分支），现在各自有能认出来的模型。

**几个值得一试的实验**：钠丢进滴了酚酞的水 ／ 铁钉泡硫酸铜 ／ 锌粒加盐酸 ／ 硝酸银滴进食盐水 ／
石灰石加盐酸 ／ 加热到沸腾看蒸汽 ／ 硝酸铵溶于水（会变冷！）／ 铝热反应 ／ 高锰酸钾受热制氧。

## 📘 初中化学实验教程（39 个实验 / 168 步）

右上角「📘 实验教程」→ **左边点一个实验**（只是看详情，不会动你的工作台）→ 按 **「▶ 开始实验」** →
教程面板让开、工作台**右侧弹出常驻的步骤面板**，从这里开始是**手把手**：

- **步骤面板**：整段流程铺开在右边 —— 5 步全列、当前这一步放大显示、做过的自动打 ✅ 并往下走。
  面板上有「📖」（完整讲解）「↺」（从第 1 步重做）「✕」（收起，点「📘 实验教程」里的「▶ 继续」能原样找回来）。
  它是**和工作台并排**的，不是浮在上面的遮罩 —— 谁都不挡谁，两侧栏在引导时会自动收窄给工作台让地方（1280 的笔记本上也放得下）。
- **它盯着你的手做**：只给当前这一步，并且**把该点的那个控件点亮**（脉冲高亮 + 👆 箭头 + 一句"点哪儿"）。
  试剂架格子、容器卡片上的「📏测量 / ⚡点燃 / 🫗倾倒 / 💨导气 / 🧻过滤 / ⚡通电」、**器材行里的「🕯 酒精灯」、
  器材卡片上的「⬆ 架上来」和「🔥 点燃」**、弹窗里的「加入」按钮，都会被精确指到；
  目标不在视野里会自动滚进来（台面横向滚动时也会拉回来）。**点错东西当场纠正**（"⚠ 刚才那步不是必需的：
  加入 氯化钠 —— 这一步要做的是「取 5 g 高锰酸钾加入试管」"），但步骤绝不会被蒙混过去。
  加热类步骤因此被拆成**三个子动作按顺序指**：先摆器材 → 再架上去 → 最后点燃。
- **卡住才提示**：12 秒没进展才给 💡 操作提示，30 秒还卡着才出现「🎬 看一遍」——**演示是最后手段，不是主路径**。
- 「📖 全览」随时切回完整讲解 + 步骤清单 + 现象/方程式/要点/安全（做完复习用）。

**手把手自己踩过的四个坑**（2026-09-27 按玩家实测报告修的，全部有回归断言）：

| 坑 | 玩家看到的现象 | 修法 |
|---|---|---|
| 单质不在试剂架上 | 实验八/九让你"在试剂架搜「铁」「镁」" —— 那个格子**永远不会出现**（货架按 `!isElem` 过滤，118 种单质只在左边周期表上） | 引导改指**元素周期表**：点「Fe 铁」→ 点「取用 5 g 铁」→ 点「加入」。两步都精确高亮 |
| 用量默认值过不了这一步 | 电解水第 1 步要 **80 mL** 水，弹窗默认 50 mL → 照引导点完，步骤永远不亮；中和那步更狠，默认 50 mL 盐酸直接冲过终点 | 弹窗用量**按这一步的计划填好**（并写明"这一步需要 80 mL"），不再说"用默认值就行" |
| 器材跨实验残留 | 实验二点着的酒精灯留在台面上，实验三的引导就指着**一盏亮着的灯**叫你"点燃" —— 一点反而熄灭，还判你点错 | 换实验时**器材一起清空**；另外引导会跳过"想要的实物状态已经成立"的项（你自己先点着灯也算数） |
| 架上去之后卡片顶出屏幕 | 抬升量写死 112 px、卡片又太高 → 1280×720 上容器顶端被裁掉（标题和按钮跑到视野外） | 按**量出来的器材高度**抬升 + 两张卡片瘦身 + 抬升量限幅（见上文"热源是实物"那段） |

**每一步都是真判定**，不是"点了就算"：判定读的是工作台的真实状态（容器里有没有这种物质、温度到没到、
气体有没有放出来、pH 多少、过滤后滤液在哪、晶体有没有析出），而且只认**本次实验里**发生的事
（不会因为你以前做过同样的反应就提前点亮）。168 步里有 148 步能直接指出"该点哪个控件"，剩下 20 步是纯观察/归纳
（看着它反应，或点「⏩ 时间」加速）。

## 🖐 拖拽装配（第十轮）

工作台上的一切都能**按住标题栏拖**（容器卡片、器材卡片都行）。拖动时会浮出一条"松手会做什么"的提示，
落点卡片上会亮虚线框：

| 拖什么 | 拖到哪 | 松手的结果 |
|---|---|---|
| 烧杯 / 锥形瓶 / 集气瓶 | 铁架台 | 放进**上格铁圈**（占了别的容器会先把它换下来） |
| 酒精灯 / 本生灯 / 喷灯 / 电热板 | 铁架台 | 塞进**下格**（下格有热源时不再接收） |
| 容器 | 热源器材 | 「⬆ 架上来」—— 直接架到灯上（玻璃器皿会被规则拦下，见下节） |
| 石棉网 | 容器 | 「⬇ 垫到容器下」（垫了明火加热才传热） |
| 温度计 / pH 计 / 量筒 / 天平 / 玻璃棒 | 容器 | 插进容器，之后点「📏 测量」就能读数 |
| 其它 | 空位 | 自由摆位（也可以用来把两份仪器拉开距离） |

拖动只改**位置和装配关系**，不绕过任何物理规则 —— 玻璃器皿拖到明火上照样被拒，并告诉你缺什么。

## 🔥 铁架台下格：什么热源都能放（第十轮）

以前"下格只放得下酒精灯"，现在是**任何热源都能进下格**：酒精灯（250 W / ≤577 °C）、本生灯（900 W / ≤1227 °C）、
酒精喷灯（1500 W / ≤1327 °C）、电热板（600 W / 无明火）。实测同一只烧杯（20 mL 水、垫石棉网）：

| 下格放什么 | 30 s 后水温 |
|---|---|
| 酒精灯 | 298 → 305 K（约 +19 °C/30 s，够做沸腾实验） |
| 本生灯 | 298 → 329 K（+31 K/30 s，快得多 —— 但烧杯到 700 K 会炸，别贪） |

## ⛔ 缺器材只提示，不白送（第十轮）

做某个操作却**没有那件器材**时，模拟器只告诉你缺什么，绝不替你变出来：

- 「🗼 配铁架台」：台面上没有铁架台或石棉网 → 提示「还差 🗼 铁架台 和 🕸 石棉网 —— 左侧器材行里先摆上」；
  三件齐了它才装配（顺序、位置、明火规则一样都不省）。
- 铁架台卡片的「⬇ 下格放热源」：台面上一件热源都没有 → 提示先摆一件，不会偷偷加一盏灯。
- `setHeater()` 这类脚本接口同样只认台面上**真的摆着**的器材，缺哪件报哪件。

（唯一的例外是**测量工具**：第九轮按用户要求，"点读数行就直接把量器插上" —— 量器是读数用的，不算装配器材。）

## 🌡 明火加热的硬规矩（第九轮）

- **烧杯 / 锥形瓶 / 集气瓶 / 水槽不能和明火直接接触**：必须「🗼 铁架台（上格放器皿）+ 🕸 石棉网 + 🕯 酒精灯（下格）」三件齐了才传热，缺一件**一点热都不给**（UI 直接标 ⛔ 原因）。
- 走正路最快的方式：**选中器皿 → 点酒精灯卡片上的「🗼 配铁架台」**，一下把三件配齐并点着；手动摆也行（摆铁架台 → 上格放容器 → 下格放酒精灯 → 垫石棉网）。
- **试管 / 坩埚 / 蒸发皿是真能直火加热的**（教材也这么写），电热板不是明火，这两类不受限制。
- 教程与脚本 API 会自动补齐石棉网 + 铁架台 —— 规则是给手玩的，不挡教学进度。

容器卡片上**只写测没测过**，数值要用量器量出来 —— 而且量器得先摆上台面、按规程使用：

| 质量 | ⚖ 电子天平 | 天平摆台面上就行（容器放台面称） |

## 哪些是简化的（不装）

- **温度是集总参数**：一个容器一个温度，没有空间温度梯度、没有局部过热。
- **玻璃器皿会炸**：玻璃失效不是"熔化"而是**热应力炸裂** —— 干烧到 700 K 左右（约 427 °C）裂；往 430 K 以上的器皿里直接倒室温液体也裂。陶瓷（蒸发皿/坩埚）的失效温度远高于加热上限，正常蒸发不会炸。炸了就是报废：内容物全洒、热源自动断开、卡片变红、台面留碎玻璃。
- **气体会留在容器里**：生成的气体先占容器气相（1 atm 理想气体，`V/24.5 × 298/T`），装不下才冒泡逸出。所以"把木炭伸进刚制好的氧气里点燃"能真的发生 —— 但 25 mL 试管的气相只存得住约 1 mmol 氧气，其余从管口跑掉，这点也是真的。
- **压力固定 1 atm**：没有真空/加压/分压，气体体积用理想气体近似但只用于换算。
- **反应速率是简化的**：`速率等级 × dt`，温度只作为条件阈值（到温才反应），**不是 Arrhenius 动力学**。
  （不过"过氧化氢自然分解很慢、加 MnO₂ 才剧烈"这类相对快慢是按真实情况单独调过的。）
- **反应库 96 条**：覆盖化合/分解/置换/中和/复分解/氧化还原/燃烧七大类常见反应，但 118 种元素里
  大多数还没有专属反应（这是本轮刻意选的"最小可玩"范围，加反应只需在 `RX_DEFS` 加一行）。
- **ΔH 的水合表不算完整**：溶液态用 ΔfH°(aq)，但表里没收录或标了"近似"的物质会退回纯态值
  （日志会分别标注"水合态生成焓 / 由生成焓算出 / 估算"，不混着说）。缺全部数据的按类别估算并标"估算"。
  实测差值举例：中和热旧算法 −104.2 → 现 −56.8（实测 −57.3）。
- **没有核反应**：放射性元素只给危险性提示，可以观察但不模拟衰变。
- **只做桌面宽屏**：没做手机/触屏适配（本轮明确不做）。

## 发布上线（GitHub Pages）

**线上地址：<https://ybbcmg.github.io/sink/chem-lab/>**

用的是和《深潜 · SINK》同一套方法：全程走 GitHub REST API（本机 `github.com:443` 间歇性被墙，
`api.github.com` 稳定 0.6s），**不用 git push**。

```bash
node tools/publish-pages.mjs   # 幂等：库/文件存在就取 sha 覆盖，顺手确认 Pages 开着
node test/verify-live.mjs      # 对**线上地址**做真浏览器验收（7 项，退出码非 0 即失败）
```

发布后必须轮询比对 md5，确认 CDN 真的换新了才算完成 —— `publish-pages.mjs` 只保证传上去了，
`verify-live.mjs` 保证线上真的能加载、零报错、零跨站请求、并且真的能跑一次化学反应。

> 为什么发在 `sink` 库的子目录：本机那份令牌是**细粒度令牌**，只授权了 `YBBCMG/sink`
> （细粒度令牌在设计上就不能建库）。想要干净网址的话：在 GitHub 建好 `chem-lab` 库、
> 把令牌授权给它，然后 `REPO_NAME=chem-lab PAGES_SUBDIR= node tools/publish-pages.mjs`。

探针会把 `window.CHEM`（游戏内所有化学/物理 API）暴露出来，脚本直接驱动世界并断言，
不靠"看起来对"。
