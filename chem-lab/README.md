# 🧪 元素实验室（chem-lab）v0.1

一个**单文件、离线可玩**的真实化学沙盒游戏：118 种元素、真实热力学物理、自动配平的真实化学反应、
玻璃器皿 + 加热 + 测量仪器，以及看得见的粒子现象（气泡 / 沉淀 / 变色 / 火焰 / 蒸汽 / 闪光）。

**双击 `index.html` 就能玩** —— 不需要服务器、不需要联网、零外部依赖（单文件 172 KB，纯 Canvas 手绘）。

里面还带一套 **📘 初中化学实验教程**：12 个教材经典实验（制氧、氧气性质、催化剂对比、制 CO₂ 与检验、
粗盐提纯、电解水、质量守恒、金属活动性、酸碱中和、生石灰放热、配制溶液），每步都自动判定。

## 怎么玩（30 秒上手）

| 想干什么 | 怎么操作 |
|---|---|
| 放一个容器 | 工作台「仪器」行点「试管 / 烧杯 / 锥形瓶 / 蒸发皿 / 坩埚」（最多 6 个）；中间是一大片空地，摆上来的东西**都能用鼠标拖着挪位置** |
| 加试剂 | 右边**试剂架**点物质 → 填用量（g / mL / mol）→ 加入；单质在**左边周期表**点元素 → 取用 |
| 摆器材 | 工作台「器材」行点 🕯**酒精灯** 250 W ／ 🔥**本生灯** 900 W ／ 🟥**电热板** 600 W —— 它会作为**一件实物**摆到台面上（各自有卡片、有自己的「🔥 点燃 / 💨 熄灭 / ✕ 收走」） |
| 加热 | **三步缺一不可**：① 摆一件器材上台面 ② 把容器**架到它上面**（拖过去，或点器材上的「⬆ 架上来」）③ 点这件器材的「🔥 点燃」。没架上去不热、没点着也不热；熄灭/收走器材立刻停热 |
| 点燃 / 搅拌 / 倒空 / 移走 | 容器卡片上的按钮 |
| 看数据 | 卡片上的 🌡温度 / ⚖质量 / 🧪体积 / pH，点「📏 测量」把读数写进日志 |
| 看公式 | 右边**现象日志**：每条反应都给出配平后的方程式、条件、现象、ΔH |
| 倾倒 / 过滤 / 导气 / 通电 | 容器卡片第二行：🫗倾倒 ／ 🧻过滤 ／ 💨导气（会弹窗选目标容器）／ ⚡通电（电解水用） |
| 跟着教程做实验 | 右上角「📘 实验教程」→ 12 个初中教材实验，工作台按清单自动摆好仪器，**手把手把该点的按钮点亮**，逐步真判定 |
| 把时间快点过完 | 右上角「⏩ 时间 ×1」循环切 ×1 / ×5 / ×20（物理一点没改，只是让同一段时间快点走完） |

引导默认开启（右下角 6 条任务），右上角「🎓 引导」可随时关掉变成纯沙盒；进度自动存在 localStorage。

**热源是实物，不是下拉框**（这一版改的）：中间那片空地是台面，容器和加热器材各是一张卡片，
都摆在台面上、都能拖。热量只在「容器确实架在这件器材上」**且**「这件器材确实点着」时才进入系统 ——
`app.heater` 每一步都按实物关系重算，所以挪走、熄灭、把器材收走都会立刻停热。
烧杯这类的传热效率还会被"没垫石棉网"打对折，酒精灯和本生灯的最高火焰温度也不一样（576.9 °C / 1226.9 °C）。
台面排不下时横向滚动，不会出现两张卡片互相压住按钮。

**几个值得一试的实验**：钠丢进滴了酚酞的水 ／ 铁钉泡硫酸铜 ／ 锌粒加盐酸 ／ 硝酸银滴进食盐水 ／
石灰石加盐酸 ／ 加热到沸腾看蒸汽 ／ 硝酸铵溶于水（会变冷！）／ 铝热反应 ／ 高锰酸钾受热制氧。

## 📘 初中化学实验教程（12 个实验 / 49 步）

右上角「📘 实验教程」打开 → 选一个实验 → **面板自动让开**，顶上出现一条引导带，从这里开始是**手把手**：

- **它盯着你的手做**：只给当前这一步，并且**把该点的那个控件点亮**（脉冲高亮 + 👆 箭头 + 一句"点哪儿"）。
  试剂架格子、容器卡片上的「📏测量 / ⚡点燃 / 🫗倾倒 / 💨导气 / 🧻过滤 / ⚡通电」、**器材行里的「🕯 酒精灯」、
  器材卡片上的「⬆ 架上来」和「🔥 点燃」**、弹窗里的「加入」按钮，都会被精确指到；
  目标不在视野里会自动滚进来（台面横向滚动时也会拉回来）。**点错东西当场纠正**（"⚠ 刚才那步不是必需的：
  加入 氯化钠 —— 这一步要做的是「取 5 g 高锰酸钾加入试管」"），但步骤绝不会被蒙混过去。
  加热类步骤因此被拆成**三个子动作按顺序指**：先摆器材 → 再架上去 → 最后点燃。
- **卡住才提示**：12 秒没进展才给 💡 操作提示，30 秒还卡着才出现「🎬 看一遍」——**演示是最后手段，不是主路径**。
- 引导带贴在顶栏下方，**不遮挡工作台**（面板那种全屏遮罩会让人点不到东西，所以手把手模式下它自动收起）。
- 「📖 全览」随时切回完整步骤清单 + 现象/方程式/要点/安全（做完复习用）。

**每一步都是真判定**，不是"点了就算"：判定读的是工作台的真实状态（容器里有没有这种物质、温度到没到、
气体有没有放出来、pH 多少、过滤后滤液在哪、晶体有没有析出），而且只认**本次实验里**发生的事
（不会因为你以前做过同样的反应就提前点亮）。49 步里有 43 步能直接指出"该点哪个控件"，剩下 6 步是纯观察
（看着它反应，或点「⏩ 时间」加速）。

| # | 实验 | 教材位置 | 关键判定 |
|---|---|---|---|
| 一 | 加热高锰酸钾制取氧气 | 上册·第二单元 | 加热到 513 K 分解、导气收集 O₂、木炭在氧气里燃烧 |

| 四 | 过氧化氢制氧：常温也能出氧气 | 上册·第二单元 | 常温冒泡放氧、瓶壁发热（放热） |
| 五 | 实验室制取二氧化碳并检验 | 上册·第六单元 | 大理石+稀盐酸冒泡、导气通入石灰水变浑浊 |
| 六 | 粗盐提纯：溶解→过滤→蒸发结晶 | 下册·第十一单元 | 食盐溶解/沙子不溶、滤液与泥沙分离、蒸发到析出晶体 |

## 哪些是真的（可复核）

| 项目 | 实现方式 | 证据 |
|---|---|---|
| **118 种元素** | 真实原子量(IUPAC 2021)、密度、熔点、沸点、电负性、常见氧化态、危险性 | 探针：Fe = 55.845 / 7.874 g·cm⁻³ / 1811 K / 3134 K 逐项核对 |
| **摩尔质量** | **不查表**，由化学式解析器按原子量累加算出（支持括号、结晶水、电荷） | CuSO₄·5H₂O → 249.677（理论 249.685）；Fe₂(SO₄)₃ → 399.858 |
| **反应配平** | 反应只写"左边有什么、右边有什么"，系数由**分数精确高斯消元求零空间**解出 | 96 条反应全部通过元素守恒 + 电荷守恒断言，0 条不配平 |
| **反应热 ΔH** | ΔH = Σν·ΔfH°(产物) − Σν·ΔfH°(反应物)；**在溶液里发生的反应用水合离子生成焓 ΔfH°(aq)**（逐物质判断，冒泡逸出的气体仍用气相值） | H₂+O₂→H₂O 算出 **−571.7 kJ/mol**（实测 −571.6）；中和热 **−56.8**（实测 −57.3）；Zn+2HCl **−153.9**；CaCO₃+2HCl **−15.2**（实测 −15.25）；Na+H₂O **−183.3 kJ/mol Na**（实测 −184） |
| **金属活动性** | K Ca Na Mg Al Zn Fe Sn Pb H Cu Hg Ag Pt Au 顺序表，决定谁能置换谁 | 铜加盐酸不反应、铁能置换铜，都由同一张表卡住 |
| **溶解性 / 沉淀** | 每种盐的真实溶解度（g/100 g 水），生成难溶物自动标 ↓ 并下沉 | AgNO₃+NaCl → AgCl↓ 0.0177 mol，原子守恒通过 |
| **热量** | Q = Σn·Cp,m·ΔT；水 Cp,m = 75.3 J/(mol·K)；金属用**杜隆-珀蒂定律** c≈3R/M；其余用每原子 25 J/(mol·K) 估算 | 烧杯+电热板 5 s 实测温升 1.76 K，与 P·η·t/C 吻合 |
| **沸腾与汽化** | 到沸点后温度被**锁在沸点**，多余能量全部按汽化潜热 40.65 kJ/mol 转成蒸汽 | 水在 373.15 K 沸腾，蒸发 0.170 mol 后温度仍 373.15 K |
| **沸点升高 / 凝固点降低** | ΔTb = Kb·b（0.512）、ΔTf = Kf·b（1.86） | 100 mL 水溶 20 g 食盐：沸点 373.15 → 374.90 K |
| **溶解热** | 真实积分溶解焓表（NaOH −44.5、NH₄NO₃ +25.7、CaCl₂ −82.8 …） | 10 g 硝酸铵溶于 80 mL 水 → **降 7.07 K**；5 g NaOH → **升 12.69 K** |
| **pH** | 强酸完全电离、弱酸 √(Ka·c) 近似，用真实 pKa/pKb（乙酸 4.76、碳酸 6.35、氨水 pKb 4.75…） | 0.1 M NaOH → 13.00；0.1 M HCl → 1.00；等量中和 → 7.00 |
| **酸碱指示剂** | 真实变色范围：酚酞 ≥8.2 变红、石蕊 5.5~7.5 红→蓝 | 钠与水生成 NaOH 后酚酞变红，探针取到 `#e0409a` |
| **浓度换算** | 按 mL 取用要过**密度 × 质量分数**（浓盐酸 37%/1.18、浓硫酸 98%/1.84） | 20 mL 浓盐酸 = 0.240 mol（真实浓盐酸 ≈12 mol/L → 0.24 mol） |
| **蒸发结晶 / 过饱和** | 溶液超过该温度下的溶解度，多余的溶质就以**晶体**析出（溶解的气体过饱和则回到气相） | 5 mL 水 + 1 g 食盐加热蒸干 → 水 0 mol、食盐变成未溶解晶体、日志记"开始以晶体析出" |
| **过滤 / 倾倒 / 导气** | 过滤把液相滤进另一容器、不溶物留在原容器；导气把气相通到另一容器（连同溶解的 CO₂ 和碳酸分解放出的 CO₂） | 粗盐提纯：滤液进蒸发皿、SiO₂ 留在烧杯；CO₂ 通入澄清石灰水 → CaCO₃ 0.0135 mol |
| **实验室真实约束** | 烧杯不能直火（须垫石棉网）：效率减半 + 提示；空容器干烧到耐温上限就停；容器容积装不下会被拒绝 | 三条各有独立断言 |

## 哪些是简化的（不装）

- **温度是集总参数**：一个容器一个温度，没有空间温度梯度、没有局部过热。
- **玻璃器皿会炸**：玻璃失效不是"熔化"而是**热应力炸裂** —— 干烧到 700 K 左右（约 427 °C）裂；往 430 K 以上的器皿里直接倒室温液体也裂。陶瓷（蒸发皿/坩埚）的失效温度远高于加热上限，正常蒸发不会炸。炸了就是报废：内容物全洒、热源自动断开、卡片变红、台面留碎玻璃。
- **气体会留在容器里**：生成的气体先占容器气相（1 atm 理想气体，`V/24.5 × 298/T`），装不下才冒泡逸出。所以"把木炭伸进刚制好的氧气里点燃"能真的发生 —— 但 25 mL 试管的气相只存得住约 1 mmol 氧气，其余从管口跑掉，这点也是真的。
- **压力固定 1 atm**：没有真空/加压/分压，气体体积用理想气体近似但只用于换算。
- **反应速率是简化的**：`速率等级 × dt`，温度只作为条件阈值（到温才反应），**不是 Arrhenius 动力学**。
  （不过"过氧化氢自然分解很慢、加 MnO₂ 才剧烈"这类相对快慢是按真实情况单独调过的。）
- **反应库 96 条**：覆盖化合/分解/置换/中和/复分解/氧化还原/燃烧七大类常见反应，但 118 种元素里
  大多数还没有专属反应（这是本轮刻意选的"最小可玩"范围，加反应只需在 `RX_DEFS` 加一行）。
- **ΔH 的水合表不算完整**：溶液态用 ΔfH°(aq)，但表里没收录或标了"近似"的物质会退回纯态值
  （日志会分别标注"水合态生成焓 / 由生成焓算出 / 估算"，不混着说）。缺全部数据的按类别估算并标"估算"。
  实测差值举例：中和热旧算法 −104.2 → 现 −56.8（实测 −57.3）。
- **没有核反应**：放射性元素只给危险性提示，可以观察但不模拟衰变。
- **只做桌面宽屏**：没做手机/触屏适配（本轮明确不做）。

## 发布上线（GitHub Pages）

**线上地址：<https://ybbcmg.github.io/sink/chem-lab/>**

用的是和《深潜 · SINK》同一套方法：全程走 GitHub REST API（本机 `github.com:443` 间歇性被墙，
`api.github.com` 稳定 0.6s），**不用 git push**。

```bash
node tools/publish-pages.mjs   # 幂等：库/文件存在就取 sha 覆盖，顺手确认 Pages 开着
node test/verify-live.mjs      # 对**线上地址**做真浏览器验收（7 项，退出码非 0 即失败）
```

发布后必须轮询比对 md5，确认 CDN 真的换新了才算完成 —— `publish-pages.mjs` 只保证传上去了，
`verify-live.mjs` 保证线上真的能加载、零报错、零跨站请求、并且真的能跑一次化学反应。

> 为什么发在 `sink` 库的子目录：本机那份令牌是**细粒度令牌**，只授权了 `YBBCMG/sink`
> （细粒度令牌在设计上就不能建库）。想要干净网址的话：在 GitHub 建好 `chem-lab` 库、
> 把令牌授权给它，然后 `REPO_NAME=chem-lab PAGES_SUBDIR= node tools/publish-pages.mjs`。

探针会把 `window.CHEM`（游戏内所有化学/物理 API）暴露出来，脚本直接驱动世界并断言，
不靠"看起来对"。
