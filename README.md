# 深潜 · SINK

一盏会发光的灯，向深渊下潜。**越贪越快，越快越瞎。**

- **深度 = 分数**，氧气是唯一生命条，归零即结束
- **加速下潜**：得分 **×2.5**，但氧气消耗 **×2.05**、视野同时收缩
- 气泡回氧、发光水母临时扩光、礁石与废弃缆线要掉氧，**擦身而过 +5** 分
- **气泡越深越稀**（间隔 ×(1 + 深度/700 × 0.9)）：深水靠捡泡续命是可行的，但**不再是净回氧的永动机**
  （原来这个系数是 4000，脚本对局 3/9 种子会跑成 300s 不朽 —— 有氧上限形同虚设）
- 越深越黑：可视半径从 360px 收到 150px
- **光照半径之外是纯黑** —— 障碍轮廓、气泡一律看不见；只有**水母是光源**，隔着黑也看得见它游过来
- 捡一只水母：视野 **+200px**，约 20 秒才衰减干净（深渊馈赠的「流萤」每级再 +60）

## 深渊压力（随深度加压）

深度会被折算成 **0→100% 的压力值**（右上角实时显示），压力同时拉动四件事：

```
压力 = 深度 / (深度 + 1500)        // 600m→29% · 1500m→50% · 4500m→75%，永远到不了 100%
```

| 深度 | 压力 | 耗氧 | 气泡含氧 | 撞击伤害 | 障碍行间隔 | 走廊宽 | 多一个障碍的概率 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 0 m | 0% | ×1.00 | ×1.00 | 15 | ×1.00 | ×1.00 | 0% |
| 600 m | 29% | ×1.14 | ×0.94 | 17 | ×0.96 | ×0.98 | 9% |
| 1500 m | 50% | ×1.25 | ×0.90 | 18 | ×0.93 | ×0.96 | 15% |
| 4500 m | 75% | ×1.38 | ×0.85 | 20 | ×0.90 | ×0.94 | 23% |

曲线是**对数式**的：前 600 米就能感觉到，之后增长越来越慢但**永不封顶**（9000m 也只到 86%），
所以它可以继续往上叠新机制而不会失控。

## 深渊馈赠（割草式三选一）

下潜到阈值就**暂停**并弹出三张卡，点一张（或按 `1` `2` `3`）拿走效果，然后继续下潜：

```
升到第 n+1 级所需深度 = 100 + 80 × (n-1)      // 100 / 280 / 540 / 880 / 1300 / 1800 …
```

16 张牌，各 5 级，效果**线性叠加**（`节氧` `耐压` 是乘算，收益递减）：

**流派纯度（1km 规则）**：选定流派之后、**1000m 之前**，每次三选一都给**自己流派的三张牌**（基础牌一张不掺，战斗牌保底在这个阶段让位）；1000m 起回到混池。

**战斗牌有保底**：战斗牌总等级 < 2 时，每次**普通**三选一必带一张战斗牌（选路线那次是专门的三张路线，不掺别的）。保底不受深度门槛限制——池里没有就把最早解锁的那张补进来，否则前两次强化会空转（实测第一次拿到战斗牌会被推到 540m）。
实测（每档抽 400 次；混池与流派两个阶段都量了，脚本见 test/verify.mjs）：

| 场景 | 带战斗牌 | 三张全为自己流派 | 旧版带战斗牌 |
|---:|---:|---:|---:|
| 300 m·没流派（保底在场） | **100%** | — | 26.5% |
| 700 m·已选法师 | **0%**（只给流派牌） | **100%** | 61.8% |
| 1200 m·已选法师（保底退场后） | **72%** | 0%（回到混池） | — |

实战一趟 3000m（AI 只想拿战斗牌）：第一次拿到战斗牌从 **540m 提前到 100m**（第一次强化就拿到）；混池段的普通三选一 400 次**全带**战斗牌（`test/verify.mjs` 实测）。

抽卡用**独立随机流**（由 `G.seed` 与 `G.level` 派生），所以同一 seed 的障碍布局不会因为抽卡而改变 —— 截图与复盘可复现。
所有强化在 `recalcMods()` 里汇总成 `G.m` 一张系数表，玩法只读 `G.m`；**加新卡 = 往 `SKILLS` 里加一行 + 在 `G.m` 里接一根线**。

按「带强化 / 无强化」同种子对拍（9 种子）：中位 **74.4s vs 71.5s**、最长 **109.6s vs 89.1s**。
即：强化**不破坏 60~120 秒的时长带**，但把天花板抬高了 —— 强化后的深度能到 1600m+，留给后续机制继续叠。

加上战斗系统后再标定（9 种子，脚本 AI 会瞄准开火）：中位 **87.6s**、最短 72.2s、最长 125.3s，**8/9 在 60~120s 带内**。
（同为 9 种子的旧版是 74~80s 中位，战斗把分布**收窄**了：能打掉挡路的障碍，但 1000m 以下开始有东西还手。）

单文件、零依赖、**零素材**（美术全程序化，音效用 WebAudio 现场合成）、零外部网络请求。

## 战斗（准星 / 普攻 / 深海猎食者）

**「在哪」和「打哪」分成两只手**：`A` `D`（或 `←` `→`、触屏拖拽）推**本体**；**鼠标就是准星**，普攻从潜艇射向准星落点。

- **普攻是 hitscan 光束**，判定宽度 = `atkHalfW`（半宽 22px），**自动连发**（间隔 `atkEvery` 0.5s），不需要按键
- 光束**同时对障碍物和怪物造成伤害**，一发打穿路径上所有命中的东西
- 初始伤害 **50**：**石头 100 血 → 两发碎**，**泥鳅 30 血 → 一发碎**；碎掉的障碍物 +6 分，怪物 +40 分
- **自动瞄准兜底**：鼠标停手 2.5s（`aimIdle`）或触屏/键盘玩家，准星自动咬住最近的怪物；一动鼠标立刻收回控制权
- 准星、光束、血条、怪物**都画在黑暗层之上** —— 光是打出去的，不该被黑暗吃掉

**深海猎食者**（`mobFrom` **1000m** 以下才出现，浅水区照旧只有地形）：

|---|---:|---|---|
| 猎手（红梭） | 150 | 加速上冲 + 横向咬人（约 1.3s 穿屏） | 撞上扣 **18 氧**，同归于尽 |
| 电袭者（紫伞） | 90 | **悬停射手**：不跟水流滚，自己慢慢游上来 | 每 1.3~2.0s 放一颗电球，命中扣 **12 氧** |
| 剃刀鲸（2000m+） | 320 | 横着冲过整屏，撞完不消失 | 撞上扣 **22 氧**，1.2s 后回来再撞 |

## 转向手感（A/D）

键盘走的是**油门**，不是开关：轻点微调，按住提速到全速。

| | 旧 | 新 |
|---|---:|---:|
| 轻点 0.16s 的峰值速度 | 620（97% 全速） | **194.6（30%）** |
| 轻点一次位移 | 106.6 px | **32.3 px** |
| 松手后漂移 | 26.3 px | **8.1 px** |
| 到达 90% 全速用时 | 0.083s | 0.417s |
| 贴边 20px 推墙的撞击速度 | 461.4 | **0.9**（软着陆） |

曲线 = `kbTapMul 0.30 → 1.0`，`kbHold 0.12s` 之后按 `kbRamp 0.35s` 走 smoothstep；
贴边 `kbSoftEdge 120px` 内线性收力，不再撞墙急停。鼠标转向仍是**比例控制**，不受影响。

## 调参旋钮

想改难度/手感都在这几个数上（`CFG`，改完刷新即可）：

| 旋钮 | 作用 |
|---|---|
| `diffHalf` | 深渊压力曲线快慢（越大越温和） |
| `mobFrom` / `mobRamp` / `mobIntro` | 刷怪起始深度 / 适应期长度 / 适应期倍率 |
| `mobCapBase` / `mobCapGain` | 同时在场上限 |
| `mobDeepen` | 深段倍率（`[0.70, 1.40]` ＝原版，**别动**：砍了局时会失控） |
| `hunterEvery` / `spitterEvery` | 两只怪的基础间隔 |
| `bubbleThin` | 气泡随深度变稀的速度（越小越难） |
| `kbTapMul` / `kbHold` / `kbRamp` | 键盘轻点档位 / 生效延迟 / 提速时长 |
| `kbSoftEdge` | 贴边缓冲宽度 |

## 联机 · 实时同屏合作 · 2026-09-26

标题页的**「联」按钮**（或 `N` / `M` 键）开面板：**创建房间** 会给你一个 4 位房间码，
朋友填码点**加入房间**就进来了 —— 底层是 **WebRTC 点对点**，中间只借 `ntfy.sh` 的公共主题递一次
「邀请码 / 应答码」（不经过我们的服务器，我们也没服务器）；不想碰第三方就点**手动模式**，
两端各复制粘贴一段 SDP，全程不走网络中间人（探针走的就是这条路，可离线自测）。

| 规矩 | 说明 |
|---|---|
| **氧气各自算** | 两个瓶子各算各的：谁捡的气泡谁喝、谁挨咬谁掉氧；击杀/噬血这类 build 收益双方都拿 |
| **倒下 10s 复活** | 氧见底 = 倒下（不能动、不能开火、怪不再盯你），10s 后原地满血回归一半氧 + 2s 无敌；**两人同时倒下才算结束** |
| **双人难度 ×2** | 只要有客人连上：怪物**血量 ×2**、**咬/撞/电伤害 ×2**（`CFG.coopMul`）。持续伤害与「按上限百分比掉氧」的机制（吸血蛭 / 缺氧带）**不翻倍** —— 15%/s 翻倍就是 3 秒必死，那不叫难度 |

**架构**：房主跑全量模拟（数值只有一份），客人只送操作（30Hz）、收快照（15Hz）、自己插值渲染 ——
客人不跑第二份物理，所以不会出现「两边怪的位置不一样」这种经典同步灾难（实测深度差 1m、怪数差 0）。
第二个人物走的是本体那套移动手感（轻点微调 / 长按全速 / 触屏拖拽），自动瞄准射击。

> **截图抓出来的真 bug（这轮最值钱的一条）**：二号位原本画在**黑暗层之下**，只要他跑出你的光照半径就是**纯黑** ——
> 探针量「p2.x 差 0px」全绿，画面上却根本找不到人（截图一放大就露馅）。现在队友跟怪一样走「生物光」那一档，
> 画在黑暗层之上，还挂了常驻名牌「潜伴」。教训：位置同步对了 ≠ 玩家能看见。
>
> 已知边界（M2 待做）：客人的技能键（Q/E/F）还没接、卡牌由房主选、断线不自动重连。
> 对称 NAT 下靠一个公共免费 TURN 中继（介意就走手动模式，但可能连不上）。

## 调参旋钮

手感与难度**全部集中在 `index.html` 顶部 `CFG`**，改一行即可重调，不用翻实现：

- `o2Drain` `boostDrainMul` —— 生存时长
- `boostRamp` `speedRamp` —— **下潜手感**：踩加速/松开的响应速度（越大越跟手，`boostRamp:24` ≈ 117ms 到 95%）
- `diffHalf` `diffGrace` —— **深渊压力曲线**：`压力 = max(0, d-grace) / (max(0, d-grace) + diffHalf)`。
  `diffGrace` 调大＝**前段缓坡起步**（玩家喊「加压太快」就动这个：宽限 160m 时 300m 处 16.7%→8.5%、600m 处 28.6%→22.7%）；
  `diffHalf` 一动会**连深水一起放松**，尾段会冒出准不朽局 —— 实测调到 1800 时 9 个种子里跑出一个 **240s** 的局
- `drainGain` `bubbleLoss` `hitGain` `rowGain` `gapGain` `extraObst` —— 压力对「耗氧 / 气泡含氧 / 伤害 / 障碍密度 / 走廊宽度 / 障碍个数」各自的增益，**全部是「压力 × 增益」的线性系数**，想更狠就一起往上加
- `hitDamage` `bubbleO2` `bubbleThin` —— 基准碰撞惩罚与补给密度
- `rowNear/rowFar` `gapNear/gapFar` `gapStep` —— 浅水段的障碍密度与走廊宽度（`gapStep` 是「保证过得去」的关键，别调太大）
- `lightNear/lightFar` `jellyLight` `jellyDecay` `jellyCap` —— 视野收缩曲线 + 水母光强/续航（`jellyDecay` 是每秒衰减量，调小＝照得更久）
- `boostMul` `boostSpeed` `baseSpeed` —— 风险收益比
- `lvBase` `lvStep` —— **强化节奏**：`lvBase` 调大＝第一张牌来得更晚，`lvStep` 调大＝后面越来越稀
- `atkDmg` `atkEvery` `atkHalfW` `atkReach` `beamT` —— **普攻**：伤害 / 连发间隔 / 判定半宽 / 射程（光束长度上限）/ 视觉残留
- `rockHP` `cableHP` —— 障碍物血量（石头 / 泥鳅）
- `aimLerp` `aimAutoR` `aimIdle` —— **准星**：跟手速度 / 自动瞄准锁敌半径 / 鼠标停手多久交给自动瞄准
- `mobFrom` `hunterEvery` `spitterEvery` `boltEvery` —— **猎食者**：出场深度与两类怪的刷新间隔（越深自动乘 `0.7+1.4×压力`）
- `hunterHP` `hunterRush` `huntDamage` `spitterHP` `spitterRush` `boltDmg` `boltSpeed` `killScore` `breakScore` —— 怪物血量·速度·伤害·击杀得分
- `SKILLS[]` —— 技能池：加一行＝加一张牌（`minD` 解锁深度、`max` 等级上限、`w` 抽卡权重）；效果接在 `recalcMods()` 的 `G.m` 上

逻辑分辨率 `W0×H0 = 960×600`，等比例居中缩放；逻辑步长固定 `1/120s`，帧率不同手感一致。

## 判定与画法（同日修的三个玩家反馈）

- **泥鳅（cable）是「一条线」，判定也必须是整条线。** 原来三处各写各的：光束只认身子**顶端一个点**
  （探针实测 上=75 中=0 下=0），冲击波只认圆心到**身子中点**的距离。现在统一走 `entBodyDist` /
  `segSegDist`（两条线段最短距离），整条身子一起算 —— 玩家口径「改成一条全是」。
- **障碍物不是光源。** 黑暗层之上的「生物光重绘」原来写的是「不是气泡、不是水母就重绘一笔」，
  而兜底分支画的是电袭者的紫伞 + 触手 —— 于是每块石头、每条泥鳅在黑暗里都顶着一只紫色水母
  （探针实测石头 918 个紫像素、泥鳅 387 个）。现在只有 `MOB_SET`（猎手/电袭者/剃刀鲸/圣盾使/电球）重绘；
  障碍物在光照半径外就该是黑的。
- **卡面文案换行。** 描述原来是单行居中不换行：护心符那条 336px 直接冲出 252px 的卡面。
  现在 `wrapText()` 按卡宽贪心断行（中文按字、`35` `10s` 这种整块不拆），整块垂直居中。
  体检覆盖 72 条文案，最宽一行 230px = 上限，超宽 0 条。

## 三条路线（第二次强化起）

第二次强化时三张路线卡一起端上来，**选一条，另外两条永久关闭**。选路线只给「技能本身」；下面那些数值要靠之后的路线牌一级一级点出来。不带路线标记的基础牌（收益 / 生存 / 机动 / 采集 / 战斗）任何路线都能抽到。

| 路线 | 主技能 | 专属牌 | 玩起来 |
|---|---|---|---|
| 法师 | Q 冲击波 | 过载 · 凝神（冷却 x0.88） · 震荡（伤害 +40） · 扩散（半径 +45） | 冷却降、伤害升、范围大 |
| 照明使者 | F 探照 | 长明 · 灼光（探照期间每秒灼伤 30） · 回春（每秒回氧 1%） · 光盾（受伤 -35%） | 开灯期间灼伤 + 回氧 + 护盾 |
| 战士 | E 突进 | 余燃 · 铁躯（氧气上限 +22） · 猛撞（撞击 +50，怪也能撞） · 噬血（撞死回氧 2.5%） | 血厚、撞击狠、吸血 |

**技能改用鼠标右键释放** —— 左手要按住 A/D 转向，Q/E/F 按着别扭。**技能不是白送的**：Lv2 的强化三选一里选定一条路线才有技能，右键 / Q E F / 右下角按钮放的都是「你选的那一个」，另外两条永久封闭（没选路线时三个按钮画虚线写「锁」）。
